# ist256-l5

## L5: Solo Lab Assignment JavaScript Exercise 

Using your previous HTML/CSS/Bootstrap solo storefront Web project user sign-up Web page add JavaScript (internal or external) code to perform proper field validation (all fields are required and check their type format). Make sure to display a message on improper validation by using Javascript to modify the textbox and show it in red. Please make sure to test your submission so that all fields are checked and required. The email field needs to check for the proper format type for example: joe@test.com.  Additionally, the Password input entry needs to be the same value as the Confirm Password field entered when performing the validation.  Make sure to reset all the red text color after a valid input has been entered. Please upload your html and CSS files to your github.io link.   Make sure to test the URL link you provide for the assignment resources.

- HTML (Page Structure) Web Storefront: The user sign-up Web Page will handle the User sign-up details form

- CSS (Page Style and Cosmetics) Web Storefront: User sign-up Web Page

- Bootstrap (Professional look) Web Storefront: Gives the look a professional display for the User-sign up Web Page

- JavaScript (page behaviors and field integrity checks) Web Storefront: Performs the field validations
 
`For example, this code would call the JavaScript function validate() and pass in the current object (input): <input type="text" class="form-control" id="username" placeholder="Enter username" onfocusout="validate(this)"> `
